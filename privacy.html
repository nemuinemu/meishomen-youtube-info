プライバシーポリシー

対象：名場面ノート自動投稿。本ツールは運営者本人専用です。現在は OAuth設定準備中で、接続・動画投稿は未実施です。以下は、利用開始時に適用するデータ取扱方針と設計であり、実装済みの安全対策や機能を保証する説明ではありません。

1. 取得・利用を予定する情報

  • youtube.upload（https://www.googleapis.com/auth/youtube.upload）：本人が事前に承認した範囲にある動画、タイトル、説明、公開設定などを本人の YouTube チャンネルへ投稿するために使用する予定です。Google の権限説明は動画の管理を含み、投稿だけに限定された権限ではありません。
  • youtube.readonly（https://www.googleapis.com/auth/youtube.readonly）：本人の投稿先を確認するため、チャンネルの識別子や名称などを参照する予定です。権限自体は YouTube アカウントの閲覧を許可するもので、チャンネル名だけに限定されません。
  • アクセストークンと更新用トークン：本人が許可した API 操作を行うために扱う設計です。Google のパスワードを本ツールで取得する設計ではありません。
  • 投稿結果の動画識別子など：本人による投稿結果の確認に必要な範囲で扱う予定です。

権限の説明は Google 公式の YouTube OAuth ドキュメント を参照してください。実際の権限要求は、機能実装後、必要な最小限に限定します。

2. 保存先と公開サイトの境界

認証情報は将来の実装でもサーバー内の本人専用保存先で扱う設計です。トークン、非公開の Google データ、投稿素材はこの公開静的サイトへ送信・保存しません。保存期間、具体的な保護方法、削除手順の実装は利用開始前に確定・確認し、本方針へ反映します。現時点で暗号化や自動削除の実装完了は表明しません。

このサイトに外部解析、広告、入力フォーム、外部スクリプトはありません。サイト独自の Cookie やブラウザー保存機能は使用しません。ただし公開後は配信事業者が配信・安全性のためアクセスログ等を扱う場合があり、外部リンク先では各事業者の方針が適用されます。

3. 共有・販売と Limited Use

Google API から受け取った情報の利用、および他のアプリへの転送を行う場合は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。利用目的をここに記載した本人向け機能に限定する方針です。

トークンおよび非公開の Google データを販売しません。広告配信・広告最適化・汎用AIモデルの学習に使用せず、その目的で第三者へ提供しません。投稿時には本人が事前に承認した範囲の動画・投稿情報を YouTube に送信します。それ以外の任意の第三者提供は行わず、法令上必要な開示がある場合は必要な範囲に限ります。

4. 接続解除とデータ削除

利用開始後のアクセス権の解除は、運営者本人が Google アカウントの接続管理 で本ツールを選び、アクセス権を削除して行います。操作の詳細は Google 公式ヘルプ を参照してください。

アクセス権の解除と保存データの削除は別の操作です。運営者本人が処理を停止し、ローカル保存データ（サーバー内の本人専用保存先に置くトークンや取得データを含む）の削除を管理する方針です。このサイトに削除機能や削除依頼フォームはありません。Google 上の投稿済み動画は接続解除のみでは削除されません。必要な動画削除は本人が YouTube 側で別途管理します。

5. 連絡先と変更

本方針やデータ取扱いに関する連絡先は Google OAuth 同意画面に表示されるサポート連絡先を参照してください。一般サポートサービスは提供しません。取扱いを変更する場合は本ページを更新し、新しい目的でのデータ利用や追加の権限要求は必要な説明・同意を経て行う方針です。

Google による情報の取扱いについては Google プライバシーポリシー を参照してください。
