名場面ノート自動投稿

動画の投稿準備を補助する、運営者本人専用の個人用ツールです。一般ユーザー登録や第三者アカウントの運用を受け付けるサービスではありません。

現在の状態：OAuth設定準備中。Google アカウントへの接続・動画投稿は未実施です。このサイトはアプリの説明を掲載するだけの静的サイトであり、ここから認証や投稿は行えません。

予定している用途

公式の YouTube Data API の使用に向け設定中です。運営者本人が管理する投稿先チャンネルの確認と、本人が事前に承認した範囲での自動投稿に限って利用する設計です。

  • 本人の投稿先チャンネルを確認し、投稿先の取り違えを防ぐ。
  • 事前に承認された対象・公開条件と権利確認・安全検査を満たす動画およびタイトル・説明などを YouTube に送信する。初回の公開承認や運用範囲の拡大は本人の確認を得る。
  • 無断転載、無承認での公開や第三者のアカウント操作には利用しない。

Google のアクセス権限

承認を求める予定の権限は youtube.upload と youtube.readonly です。用途と権限の範囲、データの扱いは プライバシーポリシー に記載しています。設定や権限の必要性は利用開始前に確認します。

このサイトと投稿ツールは別です

認証情報や Google API 経由のデータは、この公開静的サイトへ送信・保存しません。ログイン機能、投稿機能、問い合わせフォーム、解析ツールは設置していません。

権利と独立性

本ツールは Google、YouTube、COVER その他の権利者の公式サービスや公式認定を示すものではありません。素材の利用許諾や収益を保証しません。利用時は 利用規約 に従い、権利者の条件を確認する方針です。
