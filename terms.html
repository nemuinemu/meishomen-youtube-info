利用規約

名場面ノート自動投稿は、運営者本人が自身の YouTube チャンネルへの動画投稿準備と投稿先確認に使用する個人用ツールです。一般ユーザー登録や第三者アカウントの代理運用は受け付けません。

現在は OAuth設定準備中で、接続・動画投稿は未実施です。本サイトは説明専用であり、認証や投稿を実行する機能はありません。

1. YouTube の利用条件

本ツールを用いて YouTube を利用する際は、YouTube 利用規約 に同意し、適用されるポリシーと法令を遵守する必要があります。本規約は YouTube 側の条件に代わるものではありません。

2. 投稿前の確認と公開承認

運営者本人が素材の著作権、肖像、音楽、引用条件、配信者・権利者のガイドラインと必要な許諾を確認します。切り抜き等を含め、素材が閲覧可能であることや API が利用可能であることは、転載や編集の許諾を意味しません。

投稿先、動画の対象、タイトル・説明の作成方針、公開範囲を本人が事前に承認した範囲で自動投稿する運用方針です。初回の公開承認や運用範囲の拡大は本人の確認を得ます。権利や公開可否が不明な素材、承認された条件の範囲外の処理は保留し、本人へ確認する方針です。権利侵害やなりすまし、スパム、権限のないアカウント操作に使用しません。

3. 非公式・非保証

本ツールは Google、YouTube、COVER やその他の権利者の公式サービスではなく、これらの認定・推奨・提携を示しません。個別素材の権利許諾、投稿成功、継続利用、審査通過、収益化や収益額を保証しません。

API や外部サービスの制限・仕様変更等で利用できない場合があります。本人が投稿結果と公開状態を確認し、必要に応じて処理を停止・修正する方針です。

4. データと利用終了

データの利用・保存・接続解除・削除の方針は プライバシーポリシー を参照してください。利用終了時の接続解除と保存データの削除は本人が管理します。このサイトには削除機能や問い合わせフォームはありません。

5. 連絡先と更新

連絡先は Google OAuth 同意画面のサポート連絡先を参照してください。本ツールは個人用であり、一般サポートサービスは提供しません。運用やデータ取扱いに変更がある場合は、利用前に説明を更新する方針です。
